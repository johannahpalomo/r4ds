1.3 Visualizing distributions

1.3.1 Categorical variables

You can use a bar graph to examine the distribution of a categorical variable! The height of the bars displays how many observations occurred with each x variable.

ggplot(penguins, aes(x = species)) +
  geom_bar()

You can reorder bars based on their frequencies! Transform the variable into a factor and then reorder the levels of that factor. Do this using the function fct_infreq().

ggplot(penguins, aes(x = fct_infreq(species))) +
  geom_bar()

1.3.2 Numerical variables

Continuous or discrete variables often benefit from some kind of transformation. You can visualize the distribution of continuous variables using histograms. bidwidth sets the width of th intervals.1

ggplot(penguins, aes(x = body_mass_g)) +
  geom_histogram(binwidth = 200)

You can also create a denisty plot, a smoothed-out version of a histogram. r4ds has a cute analogy of draping a spaghetti noodle over the histogram.

ggplot(penguins, aes(x = body_mass_g)) +
  geom_density()

(`stat_density()`).

1.4 Visualizing relationships

Sometimes you want to visualize the relationships between two variables. Frankly, often you want to do this.

1.4.1 A numerical and a categorical variable

You can use side-by-side box plots to visualize relationships between numerical and categorical variables. Each boxplot consists of:

  • A box that indicates the range of the middle half of the data (interquartile range/IQR stretching from 25th percentile to 75th percentile).
    • In the middle of the box, a line displays the median of the distribution.
    • WHO CARES? Gives a sense of spread of the distribution adn whether or not the distribution is symmetric about the median or skewed to one side.
  • Visual points that display observations that fall more than 1.5 times the IQR from either edge of the box.
  • A line (or whisker) that extends from each end of the box and goes to the farthest non-outlier point in the distribution.

What’s the distribution of body mass by species using geom_boxplot()?

ggplot(penguins, aes(x = species, y = body_mass_g)) +
  geom_boxplot()
Warning: Removed 2 rows containing non-finite outside the scale range
(`stat_boxplot()`).

You can also make density plots! Here, linewidth changes the thickness of the lines.

ggplot(penguins, aes(x = body_mass_g, color = species)) +
  geom_density(linewidth = 0.75)
Warning: Removed 2 rows containing non-finite outside the scale range
(`stat_density()`).

Here, by mapping species to both color and fill and using the alpha aesthetic, we color in the area under the curve with a 50% opacity.

ggplot(penguins, aes(x = body_mass_g, color = species, fill = species)) +
  geom_density(alpha = 0.5)
Warning: Removed 2 rows containing non-finite outside the scale range
(`stat_density()`).

r4ds takes note of the following terminology:

  • We map variables to aesthetics if we want the visual attribute represented by that aesthetic to vary based on the values of that variable.
  • Otherwise, we set the value of an aesthetic.
  • Basically, mapping means we put variable values in charge of the aesthetics while setting means we, the user, are in charge of the aesthetics.

1.4.2 Two categorical variables

Stacked bar charts!! I use these all the time. Wow. Now I can hopefully stop using Claude to figure this out. Instead this knowledge will live in my brain and also these notes. The next two plots both display the relationship between island and species (where do species tend to live?).

This is just a plain ol’ frequency plot.

ggplot(penguins, aes(x = island, fill = species)) +
  geom_bar()

THIS is a relative frequency plot, accomplished by setting position = "fill" in the geom. Compares the species distribution across island since we’ve accounted for the unequal number of penguins on each island.

ggplot(penguins, aes(x = island, fill = species)) +
  geom_bar(position = "fill")

Note that the y-axis label reads “count”, which is technically incorrect for the relative frequency graph. We can override this default by adding a labs() layer.

ggplot(penguins, aes(x = island, fill = species)) +
  geom_bar(position = "fill") +
  labs(y = "proportion")

1.4.2.2 Three or more variables

We can incorporate more variables into a plot by mapping them to additional aesthetics. Below you can change the colors to represent species and shapes to represent islands:

ggplot(penguins, aes(x = flipper_length_mm, y = body_mass_g)) +
  geom_point(aes(color = species, shape = island))
Warning: Removed 2 rows containing missing values or values outside the scale range
(`geom_point()`).

Too many aesthetic mappings can make it difficult to understand what’s going on. We can split plot into facets, subplots that each display one subset of the data. We can do this by adding a facet_wrap() layer. The first argument is a formula created bywith ~ followed by a variable name. The variable we pass to facet_wrap() should be categorical.

ggplot(penguins, aes(x = flipper_length_mm, y = body_mass_g)) +
  geom_point(aes(color = species, shape = species)) +
  facet_wrap(~island)
Warning: Removed 2 rows containing missing values or values outside the scale range
(`geom_point()`).

1.5 Saving your plots

You can use ggsave() to save your plots. ggsave() saves the plot most recently created to disk. You can specify the width and height; if you don’t, dimensions will be taken from the current plotting device. Wickham and co. recommend using Quarto, which is what I’m doing here.

ggplot(penguins, aes(x = flipper_length_mm, y = body_mass_g)) +
  geom_point()
ggsave(filename = "penguin-plot.png")

R code problems will happen! This is normal. r4ds recommends these troubleshooting tips.

  • Make sure all ( are matched with a )
  • Make sure all " are paired with another "
  • Check your console. If the line starts with a +, R thinks you haven’t written a complete expression. You can usually start over by pressing ESC.
  • The + in ggplot2 graphics has to come at the end of the line, not a start
  • Look for help by running ?function_name in the console or by highlighting the function name and pressing F1.
  • Look at the error message. If you don’t understand it, try googling the error message.

  1. Note that this is not that complicated; when I took PLCY, I thought there was a “correct” bin width but instead it’s a visualization choice. What best illustrates the data? That’s the correct bin width. Much more subjective.↩︎
