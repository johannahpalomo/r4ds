Variable names are followed by abbreviations that tell you the type of each variable. Types matter because they can impact the operations we can perform on a column.

  • <dbl> = double (aka real numbers)
  • <chr> = character (aka strings)
  • ` = date-time

3.1.1 dplyr basics

dplyr verbs (functions) have some things in common.

  1. The first argument is always a dataframe
  2. The subsequent arguments typically describe which columsn to operate on using the variable names (without quotes)
  3. The output is always a new dataframe

Verbs are often combined using the pipe |>. The pipe takes things on its left and passes it along to the function on the right.

flights |>
    filter(dest == "IAH") |>
    group_by(year, month, day) |>
    summarize(
        arr_delay = mean(arr_delay, na.rm = TRUE)
    )

3.2 Rows

Important verbs that operate on rows of datasets:

  • filter(): changes which rows are present without changing their order. Doesn’t affect cols.
  • arrange(): changes the order of rows without changing which are present. Doesn’t affect cols.
  • distinct(): finds rows with unique values. Can optionally modify cols.

When running filter(), dplyr executes the filtering operation, creates a new df, and prints it. Doesn’t modify existing flights df because dplyr functions don’t modify their inputs. Must use <- to save results.

jan1 <- flights |>
  filter(month == 1 & day == 1)

Note that (month == 1 | 2) does NOT do the same thing as (month == 1 | month == 2) OR (month %in% c(1,2)).

3.5.3 The slice_ functions

Five handy functions that allow you to extract specific rows within each group:

  • df |> slice_head(n = 1) takes the first row from each group
  • df |> slice_tail(n = 1) takes the last row in each group
  • df |> slice_min(x, n = 1) takes the row with the smallest value of column x.
  • df |> slice_max(x, n = 1) takes the row with the largest value of column x.
  • df |> slice_sample(n = 1) takes one random row

You can vary n to select more than one row, or instead of n =, you can use `prop = 0.1 to select (e.g.) 10% of the rows in each group. For example, following code finds the flights that are most delayed upon arrival at each destination:

  group_by(dest) |>
